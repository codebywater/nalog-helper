# nalog-helper

[![tests](https://github.com/codebywater/nalog-helper/actions/workflows/tests.yml/badge.svg)](https://github.com/codebywater/nalog-helper/actions/workflows/tests.yml)
![license](https://img.shields.io/badge/license-MIT-blue)

**Сколько налогов и взносов платить ИП на УСН 6% и 15% и самозанятому — по выписке из банка.**

Загружаете CSV-выписку, и помощник находит поступления, отделяет их от переводов самому себе и кэшбэка, считает налог и взносы за год, показывает календарь платежей и предупреждает, если доход подбирается к лимиту.

### 👉 [Посчитать онлайн](https://codebywater.github.io/nalog-helper/) — без установки и регистрации

**Выписка не покидает ваш компьютер.** Всё считается в браузере, а странице запрещено отправлять что-либо в интернет: это закреплено политикой безопасности (CSP), проверить можно в [исходном коде](docs/index.html).

> English summary: a local, privacy-first tax estimator for Russian sole proprietors (USN 6% and 15%) and self-employed (NPD): a web page that runs entirely in the browser, plus a Node.js CLI and a Claude Code skill. Drop a bank statement CSV, get income, taxes, social contributions and a payment calendar. Nothing leaves your machine.

## Что умеет

- **Разбирает выписку из любого банка**: ищет колонки «Дата операции» (или «Дата поступления»), «Сумма» или «Приход/Расход», «Назначение», «Плательщик». Понимает `;`, `,` и табуляцию, UTF-8 и Windows-1251, шапку после длинной преамбулы, ячейки с переносом строки (Excel), даты `ДД.ММ.ГГГГ`, `ДД.ММ.ГГ`, `ГГГГ-ММ-ДД` и суммы вида `−1 500,00`, `1 500,00 р.`, `(1 500,00)`. У Т-Банка и ВТБ берёт сумму в рублях счёта, отклонённые операции пропускает. Строки, которые не удалось прочитать, не теряются молча — о них есть предупреждение.
- **Несколько выписок сразу** (разные счета и банки): каждая разбирается со своей шапкой, операции складываются.
- **Отделяет доход от не-дохода**: переводы между своими счетами и со своего счёта ИП, возвраты вам (налога, займа, ошибочных платежей), кэшбэк и займы в расчёт не идут. Переводы от физлиц по СБП, переводы от ИП и непонятные «возвраты» помечаются «проверить». Выручка по эквайрингу считается доходом до вычета комиссии банка, комиссия — расходом.
- **Возвраты покупателям** (возврат предоплаты, аванса) уменьшают доход в периоде возврата — для всех режимов и проверок лимитов.
- **УСН «Доходы» 6%**: авансы за квартал, полугодие и 9 месяцев, налог за год. Налог уменьшается на взносы ИП за себя, а с работниками — на взносы за себя и за работников, но не больше чем наполовину. Ограничение 50% действует, как только отмечено «Есть работники», даже без суммы.
- **УСН «Доходы минус расходы» 15%**: расходы берутся из выписки (без налогов, переводов себе и снятия наличных) или вводятся вручную; взносы за работников добавляются к расходам отдельно. Учитываются взносы в расходах, минимальный налог 1% и региональная ставка (не выше 15%).
- **Взносы ИП**: фиксированная часть и 1% с дохода свыше 300 000 ₽ (для УСН 15% — с разницы доходов и расходов).
- **НПД (самозанятый)**: 4% с физлиц, 6% с компаний и ИП, вычет 10 000 ₽. Вычет даётся один раз за всё время: если вы уже были самозанятым, укажите остаток из «Мой налог» (поле на странице или `--npd-deduction-left`).
- **Сравнение режимов**: показывает, что выгоднее при вашем доходе. С работниками НПД недоступен.
- **Календарь платежей и уведомлений в .ics**: авансы и налог по УСН, взносы, уведомления об авансах (до 25 апреля, июля и октября — если аванс к уплате больше нуля) и декларация по УСН. Напоминание за 3 дня, сроки на выходных переносятся на понедельник.
- **Предупреждения**: лимит самозанятого 2,4 млн ₽, порог НДС на УСН (с какого числа появляется НДС), лимит УСН.

## Откуда цифры (2026 год)

| Параметр | Значение |
|---|---|
| Фиксированные взносы ИП | 57 390 ₽, срок — 28.12.2026 |
| Взнос 1% | с дохода свыше 300 000 ₽, максимум 321 818 ₽, срок — 01.07.2027 |
| Авансы по УСН | 28 апреля, 28 июля, 28 октября; налог за год — 28 апреля следующего года |
| Уведомления об авансах по УСН | 25 апреля, 25 июля, 25 октября; декларация за год — 25 апреля следующего года |
| Вычет по НПД | 10 000 ₽ один раз за всё время (ст. 12 422-ФЗ) |
| Порог освобождения от НДС на УСН | 20 млн ₽ |
| Лимит доходов на УСН | 490,5 млн ₽ |
| Лимит дохода самозанятого | 2,4 млн ₽ |

Все параметры лежат в одном месте — `PARAMS` в [docs/nalog.js](docs/nalog.js). Если нашли ошибку или цифры поменялись, откройте issue со ссылкой на НК РФ или разъяснение ФНС.

## Ограничения

Расчёт ориентировочный и **не заменяет бухгалтера**. Сейчас не учитываются:

- патент, ОСНО, торговый сбор;
- налоговые каникулы и пониженные ставки УСН 6% в регионах;
- НДС для тех, кто превысил порог: помощник только предупреждает, с какого числа он появляется (с 1-го числа месяца после превышения 20 млн ₽; если доход за прошлый год был больше 20 млн ₽ — с 1 января). Доход прошлого года помощник не видит;
- праздничные дни при переносе сроков (учитываются только выходные);
- НДФЛ за работников: в выписке он уплачивается в составе ЕНП вместе с вашими налогами, поэтому для УСН 15% его нужно добавить к расходам вручную;
- операции в иностранной валюте без суммы в рублях: они пропускаются с предупреждением.

Упрощения: взносы за год уменьшают налог уже с первого квартала; расходы, введённые вручную, распределяются по кварталам пропорционально доходу, а взносы за работников — поровну; возврат покупателю, который больше дохода квартала (месяца для НПД), вычитается из предыдущих периодов; выручка по эквайрингу считается полученной от физлиц (ставка НПД 4%). Вычет НПД по умолчанию считается неиспользованным (10 000 ₽) — это видно в карточке НПД и в отчёте. Самозанятым нельзя перепродавать товары, поэтому для селлеров маркетплейсов с перепродажей режим НПД недоступен, даже если по деньгам он выгоднее.

## С ИИ-агентом: Claude Code

Скилл `nalog-helper` считает то же самое, но в разговоре: уточняет спорные поступления («это оплата клиента или личный перевод?»), помогает отделить расходы бизнеса от личных и сохраняет календарь платежей.

```bash
claude plugin marketplace add codebywater/nalog-helper
claude plugin install nalog-helper@nalog-helper
```

Потом попросите агента: «Посчитай мои налоги по выписке vypiska.csv».

Скрипт можно запустить и без агента (нужен Node.js 18+):

```bash
node skills/nalog-helper/scripts/nalog-cli.js vypiska.csv --expenses 900000 --ics nalogi.ics
node skills/nalog-helper/scripts/nalog-cli.js sber.csv tbank.csv --employees "120 000" --npd-deduction-left 0
node skills/nalog-helper/scripts/nalog-cli.js --help   # все параметры
```

## Для разработчиков

```bash
git clone https://github.com/codebywater/nalog-helper
cd nalog-helper
npm test                         # тесты на встроенном node:test, без зависимостей
python3 -m http.server -d docs   # открыть страницу на http://localhost:8000
```

Ядро расчёта — [docs/nalog.js](docs/nalog.js): работает и в браузере, и в Node. Интерфейс — [docs/app.js](docs/app.js). Пример выписки — [examples/vypiska-primer.csv](examples/vypiska-primer.csv).
